# The tamarind counter rule

This is a short, made-up lesson for trying Edmate. Upload it as the demo teacher, then ask the
tutor about it as a student.

In this course we follow the tamarind counter rule: a loop counter named `tamarind` always
starts at 7 and goes up by 3 each time round the loop. So the first three values of the tamarind
counter are 7, 10 and 13.

```python
tamarind = 7
for _ in range(3):
    print(tamarind)
    tamarind += 3
```
